🚀 Coding Practice Tracker

A full-stack web application that allows students to track and manage their coding practice through a personalized dashboard.

✨ Features

User Authentication (Register & Login)

Add, edit, delete coding problems

Track difficulty and platform

Responsive dashboard UI

Full CRUD functionality

🛠 Tech Stack

Frontend: React.js, JavaScript, HTML, CSS
Backend: Node.js, Express.js
Database: MySQL
Tools: Git, GitHub

▶️ Run Locally
# Backend
cd server
npm install
node index.js

# Frontend
cd client
npm install
npm start
