📘 Coding Practice Tracker

A full-stack web application designed to help students track their coding practice, manage problems, and stay consistent with their learning journey.

🚀 Features

🔐 User Authentication

Secure registration and login
Each user has their own private dashboard

🧠 Problem Management

Add coding problems with title, platform, difficulty, and status
Edit and delete problems anytime
View all saved problems in one place

📊 Dashboard View

Clean and aesthetic UI
Easy filtering using dropdowns
User-friendly design for students

🎨 Modern UI

Consistent design across Login, Register, and Dashboard
Background visuals related to coding & algorithms
Responsive layout



🛠 Tech Stack

Frontend

React.js
CSS (custom styling)
Fetch API

Backend

Node.js
Express.js
MySQL

Tools

Git & GitHub
VS Code
Postman (API testing)
